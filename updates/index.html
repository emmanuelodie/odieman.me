Reference list · AWaRe groups, ATC codes & WHO DDDs

AWaRe & DDD reference list

AMS Pro, PPS Pro and VigiWard classify antibiotics by the WHO AWaRe groups and count their use in WHO Defined Daily Doses. WHO revises AWaRe every two years and the ATC/DDD Index every year. This one file lets every copy of the tools take up the new list without a new download.

How to use it

  1. Open the tool and go to Reference lists: in AMS Pro under Setup, in PPS Pro under Settings, in VigiWard in the Data hub.
  2. Press Check for updates. The tool downloads this one file and shows what would change for it and for your data (for example, how many dispensing lines would change AWaRe group). Nothing from your computer is sent.
  3. Press Apply update if you agree. The list in use is saved with your data, and AMS Pro names it on the ATC/DDD export. Go back to the built-in list undoes it at any time.
  4. No internet on the computer that runs the tool? Download the file above on another computer, bring it on a flash drive and use Load update file.
The tools read this file; they never change it. Each tool checks every entry before using it (AWaRe group, ATC code format, DDD values) and refuses a file that is damaged or not in the expected format. Anti-TB medicines (ATC J04, such as rifampicin) stay outside the tools’ AWaRe counts, as before, because they are managed by the TB programme.
