Reviewer's page

Every number traces to a named method.

This page exists for the person whose job is to be skeptical: a biostatistician, an AMS committee chair, a TMDA or MOH reviewer. Below is the exact arithmetic behind every figure the tools produce — not a marketing description of it.

Wilson score interval (proportions & prevalence)

Used for: PPS point-prevalence estimates, ward-level proportions, guideline-compliance rates. Replaces the common but statistically weaker practice of reporting a bare percentage.

z = 1.96 // 95% confidence p̂ = x / n d = 1 + z²/n center = (p̂ + z²/2n) / d half-width = z · √(p̂(1−p̂)/n + z²/4n²) / d 95% CI = [center − half-width, center + half-width], clamped to [0, 1]

This is the textbook Wilson score interval — it behaves correctly at small sample sizes and near 0%/100%, where the more common normal-approximation interval (Wald interval) breaks down and can return nonsensical bounds. The tools flag any estimate built on n < 20 as low-confidence rather than reporting a falsely precise interval.

Applies in: PPS Pro (prevalence, ward breakdowns), VigiWard (sequence-symmetry proportions)

AWaRe classification, with country overrides

Every antibiotic dispensed or prescribed is tagged Access, Watch, or Reserve — WHO's framework for antimicrobial stewardship targets.

The base classification follows WHO's global AWaRe list. Layered on top is a country-override table — currently populated for Tanzania, with WHO-generic and Kenya variants also present in the lookup — that reclassifies specific agents where national Standard Treatment Guidelines diverge from the WHO default. The most consequential Tanzania overrides:

AgentWHO globalTanzania STG
Meropenem / Imipenem / ErtapenemWatchReserve
Sulbactam + CeftriaxoneWatchReserve
Amoxicillin + Clavulanic acidAccessWatch
Flucloxacillin + AmoxicillinAccessWatch

This matters for interpretation: a report run under WHO-generic rules and one run under Tanzania STG rules will show different Access/Watch/Reserve splits for the same underlying prescribing — not because prescribing changed, but because the ruler changed. Every AWaRe report states which rule set produced it.

Benchmarks used (Tanzania targets): Access ≥ 60% · Watch ≤ 30% · Reserve ≤ 5%

DDD / 100 patient-days

Antimicrobial consumption normalized to WHO ATC/DDD methodology, the standard unit for comparing consumption across time periods or facilities regardless of ward size.

DDD (per agent) = total grams dispensed ÷ WHO-assigned DDD for that agent (route-specific) DDD / 100 patient-days = ( Σ DDDs ÷ patient-days ) × 100

Patient-days can come from two sources, and the tools are explicit about which one produced a given figure: measured (entered directly from IPC/ward patient-day logs — the preferred, higher-confidence source) or estimated (beds × occupancy rate, used only when no measured patient-days figure has been entered, and always labeled as an estimate in the output). Days of therapy (DOT) per 100 patient-days is computed alongside DDD as a cross-check, since the two metrics can diverge when dosing patterns are unusual.

Applies in: AMS Pro consumption dashboards, ward and facility-level trend charts

Cost trajectory (linear regression)

Used only for the monthly cost/consumption trend line — deliberately kept as simple, transparent ordinary least squares rather than a more opaque forecasting model.

x = month index (0, 1, 2, …) slope = (n·Σxy − Σx·Σy) / (n·Σx² − (Σx)²) intercept = (Σy − slope·Σx) / n

The tool refuses to render a trend line at all with fewer than three months of data, and every chart is labeled "trend, not a forecast" — extrapolation is a mathematical property of a fitted line, not a claim about the future. Savings scenarios shown alongside cost trends are a plain multiplication (a user-adjustable percentage × current Watch/Reserve spend), never a modeled projection.

Sequence symmetry analysis (signal detection)

Used for: flagging potential adverse-drug-reaction signals and prescribing-cascade patterns from pharmacy dispensing sequences alone, without needing a formal causality-coded dataset.

For each drug pair (A, B), the tool counts patients where A preceded B versus B preceded A within a defined window, then applies a Wilson confidence interval to the forward/total proportion and transforms it into a ratio confidence interval via p / (1−p). This transform is valid because it is monotonic — a correct confidence interval on a proportion remains a correct confidence interval after a monotonic transform.

A signal is only flagged when the lower confidence bound clears a ratio of 1 and there are at least 5 discordant pairs — a deliberate minimum-power guard against false positives on sparse data. Each ratio is reported both crude and adjusted for prescribing trends (divided by the null-effect sequence ratio expected from how the two drugs' use changed over the period), and every flagged signal is labeled hypothesis-generating, not proof of causation — it tells a pharmacist where to look, not what the answer is.

Applies in: VigiWard cascade/signal detection module

IPC benchmarks (Tanzania NIPCG 2018)

Infection prevention and control indicators are scored against Tanzania's own national guideline, not an imported international default.

Hand hygiene, PPE compliance, sharps safety, housekeeping, and linen management indicators cite specific sections of the Tanzania National Infection Prevention and Control Guidelines, June 2018 (MOHCDGEC) — for example, Part 2 §2.3 on hand hygiene, Part 2 §2.4 on PPE, and Part 3 §3.5 on environmental cleaning. Each indicator in the tool links back to the section of the national guideline it's drawn from, rather than a generic WHO IPC checklist.
