# odieman logo

One mortar, three pestles. Download any file with the download button on its page.

| File | Use it for |
|---|---|
| odieman-logo-no-tagline | Websites, documents, slides |
| odieman-mark | The mortar alone: icons, stickers, watermarks |
| odieman-profile-picture | WhatsApp, Facebook, LinkedIn, X (survives the round crop) |
| *-on-dark | Versions for dark or photo backgrounds |

PNG files have see-through backgrounds and are large enough for phones, social media and slides.
SVG files stay sharp at any size: use them for posters, banners, T-shirts and print.
