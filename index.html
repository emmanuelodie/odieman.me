Methodology, not magic

Every number these tools produce traces back to a named statistical method — the kind a reviewing biostatistician can check line by line.

Wilson score intervals

Prevalence and proportion estimates carry a proper 95% CI (z=1.96), not a bare percentage — with a small-sample warning below n=20.

AWaRe + country overrides

WHO's global Access/Watch/Reserve classification, layered with Tanzania STG-specific reclassifications (e.g. meropenem and sulbactam-ceftriaxone to Reserve).

Sequence symmetry analysis

Drug-cascade signal detection using a Wilson CI on the forward/reverse prescribing ratio — flagged only above a minimum discordant-pair threshold.

Why these tools are offline-first

Most hospital-facility software in this region assumes reliable connectivity and a maintained server. These tools assume the opposite, on purpose.
