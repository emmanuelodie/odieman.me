Why these tools exist

Too much of pharmacy data stops at collection: it is recorded, stored and summarised by hand, and reaches the committee days or weeks later. These tools exist to move pharmacists along the whole line, so the same data ends in a decision.

Collectwhat the hospital system already records; no new forms
AnalyseAWaRe, DDD and DOT, prevalence, ADR signals: done by the tool
Reportone click: committee report, ward feedback, WHO and TMDA formats
Decidewhich ward, which drug, which patient to act on first

For each tool, three questions are answered plainly: what data it needs, what one click gives you, and which decision it guides. The live demos below show all three on a simulated hospital, so you can see each step for yourself.

Methodology, not magic

Every number these tools produce traces back to a named statistical method — the kind a reviewing biostatistician can check line by line.

Wilson score intervals

Prevalence and proportion estimates carry a proper 95% CI (z=1.96), not a bare percentage — with a small-sample warning on thin data.

AWaRe + country view

WHO's global Access/Watch/Reserve classification, with the Tanzania STG/NEMLIT 2021 grouping shown side by side and checked against it, so the ruler used is always stated.

Change that is real, not noise

Laney p′ control charts, Cochran–Armitage trend tests and exact Poisson spike tests separate genuine change from ordinary month-to-month variation.
