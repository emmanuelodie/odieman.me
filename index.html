Methodology, not magic

Every number these tools produce traces back to a named statistical method — the kind a reviewing biostatistician can check line by line.

Wilson score intervals

Prevalence and proportion estimates carry a proper 95% CI (z=1.96), not a bare percentage — with a small-sample warning on thin data.

AWaRe + country view

WHO's global Access/Watch/Reserve classification, with a Tanzania STG/NEMLIT view shown side by side, so the ruler used is always stated.

Change that is real, not noise

Laney p′ control charts, Cochran–Armitage trend tests and exact Poisson spike tests separate genuine change from ordinary month-to-month variation.

About

Built by a pharmaceutical technician, using antimicrobial stewardship and pharmacovigilance experience gained across hospital pharmacy practice — for the same reason most hospital tools in this region don't exist yet: because nobody else was going to build it first. The tools grew out of the day-to-day work of a hospital AMS committee and have been used with real hospital data, not just simulated in a lab.
